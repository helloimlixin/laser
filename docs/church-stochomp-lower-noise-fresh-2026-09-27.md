# Fresh Church run with lower coefficient noise, 2026-09-27

[Training run](https://wandb.ai/helloimlixin-rutgers/laser/runs/church-stochomp-fresh-t003125-k700ct09-b2048-h100x5-20260927-r2) repeats the recipe behind the matched FID **9.6012** checkpoint with coefficient target temperature **0.03125**, reduced from **0.0625**. This is a new randomly initialized stage-2 transformer; the frozen tokenizer is retained.

The OMP trajectory temperature stays **0.0625**. Its 16-trajectory supports, continuous normalized coefficients, labels, tokenizer, coefficient bins, and depth scales are unchanged. For the coefficient kernel exp(-(c-bin)^2 / temperature), halving temperature halves the interior variance and reduces standard deviation from approximately 0.17678 to 0.125. Finite bin boundaries truncate this kernel. This experiment changes training targets; coefficient sampling temperature remains 0.9.
