The autoencoder produces a structured but partly continuous latent representation: the support of $\boldsymbol{\gamma}_i$ is discrete, while its nonzero coefficients are real-valued. For a categorical autoregressive prior, we fit a finite vocabulary of vector contributions to the frozen encoder features. The Stage-1 dictionary, encoder, and decoder are kept fixed during this offline fit and throughout prior training.

\paragraph{Sparse coefficient tokenization.}
Let $\boldsymbol{z}_i\in\mathbb{R}^{C}$ denote the raw encoder feature at latent site $i$. At each residual depth $k\in\{1,\ldots,K\}$, the tokenizer has a separate lookup table
\begin{equation}
    E_k=\{e_k(v)\in\mathbb{R}^{C}:v\in\mathcal{V}\},
    \qquad \mathcal{V}=\{0,\ldots,T-1\}.
    \label{eq:token-contribution}
\end{equation}
Each integer selects one complete vector contribution, including its direction and magnitude. The vectors are optimized independently within each residual depth. Depth is implicit in the token position and determines which lookup table is used. Unless otherwise specified, our ImageNet configuration uses $C=256$, $K=4$, and
\begin{equation}
    |\mathcal{V}|=T=24{,}576.
\end{equation}
One entry in each table is fixed to zero, $e_k(0)=\boldsymbol{0}$, and is included in these $T$ choices. There are $KT$ stored vectors in total, giving 98,304 vectors in the default configuration and $T$ categorical choices at each token position. Each $256\times256$ image is represented by an $8\times8\times4$ array of 256 integers. No separate coefficient token is required.

We fit the residual vector tables offline using encoder features from 50,000 class-balanced ImageNet training images (50 per class), with random crops and horizontal flips. Fitting alternates greedy residual assignments and regularized centroid updates. We vary the number of vectors per depth while keeping the encoder, decoder, residual depth, fitting data, initialization rule, and optimization budget fixed. Each configuration uses 24 fitting passes and a common vector gain of 1.025, established using 10,000 disjoint training images. All vector tables are frozen before prior training.

For deterministic reconstruction, we use native greedy residual quantization. Starting from $\boldsymbol{r}_{i,0}=\boldsymbol{z}_i$, we compute
\begin{equation}
    t_{i,k}=\underset{v\in\mathcal{V}}{\operatorname{arg\,min}}
        \|\boldsymbol{r}_{i,k-1}-e_k(v)\|_2^2,
    \qquad
    \boldsymbol{r}_{i,k}=\boldsymbol{r}_{i,k-1}-e_k(t_{i,k}).
    \label{eq:token-assignment}
\end{equation}
The discrete latent feature passed to the frozen decoder is
\begin{equation}
    \widetilde{\boldsymbol{z}}_i
    =\sum_{k=1}^{K}e_k(t_{i,k}).
    \label{eq:token-reconstruction}
\end{equation}
Encoding selects fixed vector contributions and transmits only integer IDs, with no per-image coefficient refitting or continuous side information. Reusing an integer at different depths is permitted; its decoded contribution is determined by the corresponding depth table.

\paragraph{Stochastic residual teacher.}
For autoregressive prior training, we use the native RQ stochastic residual teacher~\citep{lee2022rqvae}. Starting from $\boldsymbol{r}^{\mathrm{tr}}_{i,0}=\boldsymbol{z}_i$, its distribution at depth $k$ is
\begin{equation}
    q_{i,k}(v)
    =
    \frac{
        \exp\!\left(-\|\boldsymbol{r}^{\mathrm{tr}}_{i,k-1}-e_k(v)\|_2^2/\tau\right)
    }{
        \sum_{u\in\mathcal{V}}
        \exp\!\left(-\|\boldsymbol{r}^{\mathrm{tr}}_{i,k-1}-e_k(u)\|_2^2/\tau\right)
    }.
    \label{eq:token-soft-target}
\end{equation}
We sample $t^{\mathrm{tr}}_{i,k}\sim q_{i,k}$ and update $\boldsymbol{r}^{\mathrm{tr}}_{i,k}=\boldsymbol{r}^{\mathrm{tr}}_{i,k-1}-e_k(t^{\mathrm{tr}}_{i,k})$. The prior is trained by soft-target cross-entropy against these conditional distributions, using the sampled prefix tokens as context. The teacher softmax covers the full vocabulary. Its temperature controls target softness and is separate from the prior's generation sampling temperature.

At generation time, the prior predicts vector IDs autoregressively, and the frozen decoder receives their sum in Eq.~\eqref{eq:token-reconstruction}. The Stage-1 dictionary, encoder, decoder, and fitted vector tables remain frozen throughout prior training.
