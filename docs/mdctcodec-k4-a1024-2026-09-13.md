## Rate accounting

Four 10-bit atom IDs at 150Hz already cost 6kbps. Coefficients cannot be omitted
from the rate. The new joint representation has 8193 possible symbols at each
of four positions (zero plus 1024 atoms times eight nonzero coefficients). Fixed
14-bit packing would cost 8.4kbps. This is **not labeled a 6kbps result**.

The training experiment targets 6kbps using real lossless Huffman payloads.
Tables use training-only per-depth counts, including a repeat-previous-frame
symbol. Counts are checkpointed, with no per-file fitting. Frame count, bit
count, CRC, and final padding count toward measured rate. Every validation
waveform is decoded from parsed payload tokens. Huffman coding is not a promise
that the target will be met; the W&B target-pass flag uses actual bytes.
The model currently has no rate penalty, so this first corrected run measures
whether its learned token statistics meet the budget. A same-rate superiority
claim requires actual rate matching, and final rate-distortion evaluation must
also apply entropy coding to the RVQ control.
