The latest steering focuses the experiment on joint atom/coefficient training. The current model already implements the valid chain rule `p(atom | past pairs) p(coefficient | past pairs, atom)`. Its two-layer coefficient micro-transformer, however, only sees the shared hidden state and the selected atom. The existing opt-in `CompoundCoefficientHistoryDecoder` is now enabled: two width-512 layers, eight heads, and 8,403,456 added parameters. Its causal attention spans all 256 completed-pair events. Inputs are the shared hidden state, current atom, previous full-pair embedding, and strictly earlier physical contributions at the current site. Its output adds to the old coefficient conditioner before the unchanged depth-specific classifier. The new output projection starts at zero; existing weights, Adam moments, parameter order, and checkpoint RNG streams are preserved. Only the new 33 parameter tensors start with empty Adam state.

This is inspired by [DCTransformer, §3.2](https://proceedings.mlr.press/v139/nash21a/nash21a.pdf), which factorizes channel, position, and value and uses separate stacked causal decoders. Its value decoder also accesses encoded partial-image context at the current position. The [supplement](https://proceedings.mlr.press/v139/nash21a/nash21a-supp.pdf) allocates substantial depth to that value decoder and uses zero-initialized residual gates. Our residual history decoder adapts that context-modeling idea to LASER; it is not a reproduction of the DCT representation or three-decoder architecture.

Atom loss weight changes from 1.5 to 1.0, so the optimized classification loss is `(atom CE + conditional coefficient CE) / 2`. The coefficient CE still uses the existing physical soft teacher; this is not hard-label clean-token likelihood. `train/joint_cross_entropy` logs the unweighted sum. The new cache audit over 16,384 images measures physical SD exactly 0.125 at each depth and expected added latent energy 0.0768%.
